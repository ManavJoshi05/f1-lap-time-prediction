# Resume Evidence Checklist

Do not write a resume claim until the evidence exists.

## Technical evidence
- [ ] Public GitHub repository with clear README.
- [ ] Reproducible installation instructions.
- [ ] Data collection script using FastF1.
- [ ] Processed feature dataset generated by code.
- [ ] At least one valid baseline model.
- [ ] At least one tuned ML model.
- [ ] Event/session-based held-out evaluation.
- [ ] MAE, RMSE, and R² reported on an untouched test set.
- [ ] Leakage audit documented.
- [ ] Feature-importance or SHAP analysis included.
- [ ] Unit tests for cleaning and feature calculations.
- [ ] Interactive dashboard or clear result visualizations.
- [ ] Limitations documented honestly.

## Resume bullet template
Built an end-to-end Formula 1 lap-time prediction pipeline using FastF1 public timing, tyre, weather, and telemetry data; engineered leakage-safe pre-lap features and evaluated gradient-boosting models using event-level holdout validation, achieving [METRIC] on [TEST DATA DESCRIPTION].

## Evidence required for placeholders
- [METRIC]: final test MAE/RMSE, not training performance.
- [TEST DATA DESCRIPTION]: exact seasons, events, sessions, and number of laps.
