# F1 Telemetry-Based Lap Time Prediction

An end-to-end, reproducible machine-learning project that predicts Formula 1 lap times from public historical session data.

## Status
In progress — Stage 1: FastF1 data ingestion and schema exploration.

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Data
Raw data is obtained programmatically through FastF1 and is not committed to this repository.
